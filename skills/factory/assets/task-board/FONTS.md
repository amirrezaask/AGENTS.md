# Font sources

The bundled Roman web fonts come from the public Claude website stylesheets:

- [Anthropic Serif](https://claude.com/_next/static/media/AnthropicSerif_Roman_Web-s.p.c28786b4.woff2)
- [Anthropic Sans](https://claude.com/_next/static/media/AnthropicSans_Roman_Web-s.p.050e7498.woff2)

Source inspected on 2026-10-28: [Claude](https://claude.com). The board serves
these files locally. Display text uses Serif; UI controls use Sans.
