# Koloop game testing

Mute the browser tab before launching or interacting with a game. Keep it muted
after navigation and reloads, including newly opened game tabs. Use browser-level
audio suppression if tab muting is unavailable. Unmute only on ADMIN's request.
Pass this requirement to any agents delegated game testing.
