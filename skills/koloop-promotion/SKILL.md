# Koloop promotion

Deliver a matching cover poster with each promotional video. For each game,
include a conversational Persian Instagram caption.

In GameBox, use `.claude/skills/instagram-publisher/SKILL.md` when available;
it defines the repo-local production workflow. Otherwise use the installed
`koloop-promo-video` skill if available. If neither exists, inspect the project's
video tools before choosing a production workflow.

Use original game artwork over a blurred copy of its backdrop, a blue-black
fade, large English title, short neon-blue Persian hook, Nunito/Vazir fonts,
and restrained Koloop branding. Follow an existing approved cover when available.
GameBox's `docs/tools/koloop-reel-covers.ts`, if present, reproduces this style.
